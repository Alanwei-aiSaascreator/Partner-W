## 铁律（自主执行期间）

1. **不碰生产**：relay / supabase 迁移 / 更新源 / 任何服务器操作，一律不做。
   （用户不在，没人能批准生产变更。）
2. **不打交付包、不发版**：用户明确说了"打包先不动"。
3. **不改 `.gitignore`**（长期纪律）。
4. **不做破坏性 git 操作**：不 rebase 别人的分支、不 force push、不 reset --hard。
5. **每刀独立提交**，随时可单独回滚；提交信息写清"为什么"。
6. **TDD + 变异验证**：先红后绿；写完实现才跑的测试必须补变异验证。
7. **每刀都要过门禁**：lint / typecheck / typecheck:tests / check:i18n / 相关测试。
8. **发现真 bug 优先修**（尤其是我自己刚引入的），但要与当前这刀分开提交或写清缘由。
9. **诚实记失败**：偶发、跳过的验证、没查的根因，都要写进提交信息与记忆。
