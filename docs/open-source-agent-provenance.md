## Partner-W authorship rules

- Preset prompts use original product language and a shared operating contract.
- Prompts describe work methods instead of fictional biographies or unverifiable credentials.
- Platform statistics, market claims, and professional advice are never presented as facts without evidence.
- Updating a source repository does not update the shipped product. Every source change requires a new review and pinned revision.
