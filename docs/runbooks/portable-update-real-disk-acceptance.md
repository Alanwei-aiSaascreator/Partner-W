# U 盘整目录更新真盘验收

## 记录信息

- [ ] 候选版本、Git 提交号、启动器版本已记录。
- [ ] `manifest.json`、`portable-files.json`、`portable.zip` 的 SHA-256 与大小已记录。
- [ ] 测试频道 URL、测试人、开始/结束时间已记录。
- [ ] 所有失败项都保留错误码、界面截图、启动器日志和更新事务目录；不得只写“打不开”。

## 盘与电脑矩阵

- [ ] exFAT 真 U 盘完整跑一轮。
- [ ] NTFS 真 U 盘完整跑一轮。
- [ ] 干净 Windows 电脑 A（未安装荣盈魔方、普通用户）完整跑一轮。
- [ ] 干净 Windows 电脑 B（不同 Windows 用户、不同 USB 控制器）完整跑一轮。
- [ ] 交付目录含中文、空格和较长路径时可启动、下载、交换并重启。
- [ ] 全程使用普通用户权限；没有依赖管理员权限或写入程序盘外的隐式步骤。

## 基础包与数据隔离

- [ ] 解压后盘根只有启动器、程序目录和使用说明，不含 `.bat`、安装器或预置用户数据。
- [ ] 只双击盘根 `荣盈魔方启动器.exe` 即可启动；不要求安装到电脑。
- [ ] 首次运行创建的 `荣盈魔方-运行数据`、`荣盈魔方工作区`、`.荣盈魔方更新` 都在同一 U 盘。
- [ ] 更新前记录运行数据目录和工作区的逐文件哈希。
- [ ] 更新成功后运行数据目录和工作区哈希不变。
- [ ] 自动回滚后运行数据目录和工作区哈希不变。

## 基础业务验收

- [ ] 新电脑上可正常登录，不会无限停在“正在准备模型/正在启动 AI 服务”。
- [ ] 付费账号能看到应有的付费模型列表。
- [ ] 选择一个付费模型完成一轮真实聊天请求和完整响应。
- [ ] 退出并重新启动后登录态、模型列表和聊天记录符合当前产品设计。
- [ ] 连续重启两次没有重复交换、重复下载或重复回滚；启动幂等。

## 正常更新路径

- [ ] 检查更新只接受 HTTPS 和正确频道。
- [ ] 下载进度、校验、解压、等待重启、交换和成功状态与真实阶段一致。
- [ ] 下载完成前旧程序仍可用。
- [ ] 退出应用后由外置启动器交换整个程序目录。
- [ ] 新程序通过主进程、数据库、窗口和 renderer-ready 健康回执。
- [ ] 成功后只清理本事务临时目录，不触碰数据、工作区或其他事务目录。
- [ ] 更新后再次启动不会重复应用同一事务。

## 故障注入

每项都要确认：错误可见、错误码正确、旧程序或回滚程序仍可启动、数据与工作区不变、重试可成功。

- [ ] 下载前断网。
- [ ] 下载中断网，再恢复网络并重试。
- [ ] 可用空间不足，空间预算在写满磁盘前拒绝。
- [ ] manifest 签名改 1 字节，报 bad signature 并拒绝解压/交换。
- [ ] ZIP 改 1 字节，报 bad hash/package integrity 并拒绝交换。
- [ ] 文件清单或解压后文件改 1 字节，报 file integrity 并拒绝交换。
- [ ] 制造程序文件锁，交换失败可见且旧版本仍完整。
- [ ] 健康回执超时，自动回滚到上一程序目录。
- [ ] 回滚完成后再次发起更新能够成功。

## 每个交换边界的进程终止测试

以下每一处都要单独跑一次“强制结束启动器/应用进程 → 再双击盘根启动器”，并核对恢复结果：

- [ ] 写入事务状态后、开始下载前。
- [ ] 下载中途。
- [ ] ZIP 下载完成、哈希校验前。
- [ ] ZIP 校验完成、解压前。
- [ ] 解压中途。
- [ ] 精确验树完成、标记 ready 前。
- [ ] 旧程序目录改名之前。
- [ ] 旧程序目录已改名、新目录尚未就位。
- [ ] 新目录已就位、应用尚未启动。
- [ ] 应用已启动、健康回执尚未完成。
- [ ] 健康回执完成、清理旧目录之前。

## 拔盘模拟

- [ ] 下载中模拟拔盘/卷消失；恢复后不把半包当成完整包。
- [ ] 解压中模拟拔盘/卷消失；恢复后只处理本事务临时目录。
- [ ] 交换前模拟拔盘；重新插入后保持旧程序可启动。
- [ ] 交换中模拟卷消失；重新插入后启动器按事务状态恢复或回滚。
- [ ] 健康等待中模拟卷消失；重新插入后不会把未确认版本标成成功。

## 验收结论

- [ ] 所有勾选项都有日志、哈希或截图证据，没有“未测但按通过处理”。
- [ ] exFAT 与 NTFS、电脑 A 与电脑 B 都通过。
- [ ] 登录、付费模型列表、真实聊天、更新成功、自动回滚、成功重试、重启幂等全部通过。
- [ ] 若仍有失败，正式 manifest 未更新，旧 manifest/package 保持可用。
