本文件是 `release/1.0.1-internal-candidate` 的集成台账。它回答一个问题：
**这个包里装了什么，为什么装，每一件的证据在哪。**

- 产品基线：`1.0.0`
- 本候选版本号：`1.0.1`
- 集成基点：`integration/p0` = `f5c476d6ea9b6e46f2e00f7def535ede1bbf22b3`

C 线 UI）的汇合点，实测为超集：

| 对照分支        | 尖端       | 相对 integration/p0                |
| --------------- | ---------- | ---------------------------------- |
| `line-b-basics` | `e39d7d55` | 已被包含（integration/p0 领先 61） |
| `line-c-ui`     | `93fcc71d` | 已被包含（integration/p0 领先 73） |

即：**integration/p0 = 1.0.0 的全部已集成内容**。候选只需要在其上叠加 1.0.1 的十刀。
