> 工作区所在的盘不支持：助手要在里面读写自己的身份文件，而在这块盘上这一步必然失败。

### 4. 结论与边界

- ✅ **判据 + 上屏 + 出口**三段都在真机上验过（不是注入式单测那种"逻辑对"）。
- ⚠️ **这条提示出现在登录之后**：登录页之前 App 不渲染就绪面板（`App.tsx` 的 entry 阶段先给 `<Login>`）。

- ⚠️ 盘上那份运行时部署**没跑完**（我只等到助手安装那一步就收了；`E:\荣盈魔方-运行数据` 14 MB）。

## 三、驱动方式（可复用，下次真机验收照这个做）

1. **拷交付骨架到盘**：0.0.27 交付夹（启动器 + 运行时 + 说明书）→ 盘根；再把 `dist/win-unpacked/*`
   盖进 `荣盈魔方/`（保留交付里原有的 `app-update.yml` / `elevate.exe`）。
   ⚠️ 拷之前**逐字核 asar sha256**（"改了源码不重建 = 测旧代码"那条纪律）。
2. **别把凭据放到可移动盘上**：profile 放本机临时目录（`--user-data-dir=<temp>`），
   会话文件从开发机 profile 拷进**临时 profile**（`safeStorage` 是 DPAPI 密文、同机同用户可解；
   与 `e2e/packaged/provision.ts` 同一套做法）。
3. **工作区路径要改对文件**：应用读的是 **`clawwork-config.json`**（不是 `config.json` —— 我栽过一次）。
4. **要一份空注册表**：网关 state 在 `<userData>/openclaw-state`（**不是** `<userData>/state`），
   删掉才会重装助手（否则它认为"已装"，什么都不会发生）。
5. **读界面用 CDP**（`--remote-debugging-port=9222` + `Runtime.evaluate` 取 `document.body.innerText`）：
   比截图可判、可 grep。点按钮同理（React 受控输入要绕过 `value` setter 再派发 `input` 事件）。
6. **别用 `node -e` 写含反斜杠的路径**（今晚栽了五次）—— 写成收参数的脚本文件。
