# 产物文件名：不撞就用干净名字 —— 实施记录

**Goal:** 助手生成的那份报告，在「产物」里就叫 `内测汇报.pptx`，不再是 `内测汇报-3f9c2a1b.pptx`。

**来由**：P2（Word/Excel）收尾时量的 —— `saveArtifactFromBuffer` → `uniqueFileName()` **总是**拼
`-<8位随机>`。那是**要交给别人**的交付物，名字难看；P2 的技能文案当时只能写一句
"名字后面会带一小串随机后缀……别向用户解释成我起的名字"。（已随本次改掉。）

**但那个后缀不是没来由的**：它保证同一任务目录里**永不覆盖**。所以改法是
**先看不撞**，而不是把后缀去掉。

## 做了什么

| 文件                                | 内容                                                                                                                                                            |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/main/workspace/safe-name.ts`   | 新增 `uniqueFileNameIn(dir, name)`：目标目录里没有同名 ⇒ 照原样用；**撞了才**退到 `uniqueFileName`（老那套带随机后缀）。`uniqueFileName` 原样保留（别处还在用） |
| `src/main/artifact/save.ts`         | `resolveArtifactDestination` 改用它（**只动这一条路**：生成文档 + "另存为"）                                                                                    |
| `test/artifact-save-name.test.ts`   | 4 条：第一份干净 / 第二份同名才带后缀且**不覆盖** / 不同名字互不影响 / 换个任务目录各用各的                                                                     |
| `test/artifact-save.test.ts`        | 那份用例把 `fs` 整个 mock 了 ⇒ 补一个 `existsSync: vi.fn(() => false)`（它断言的是 DB/复制/删除，不看名字）                                                     |
| `our-skills/document-deck/SKILL.md` | 删掉"名字会带随机后缀"那段（现在是干净的）                                                                                                                      |

## 刻意**没**动的两条路

- `context/file-import.ts`：它自己有一套发布期冲突处理（重试 + 不覆盖已存在的目标），
  命名不是它唯一的保护。
- `inbox/save.ts`：附件落盘，同理。

⇒ 所以 `uniqueFileName` 一个字节没改，那两条路的行为与测试全不变。

## 读数（本机实跑）

- 桌面端全量：**308 个测试文件 / 3241 passed + 2 skipped**（改完这一刀之后跑的）
- 变异电池 **4 条 = 3 杀 + 1 对照**，RC=0：
  - 退回旧行为（无条件加后缀）⇒ 3 条红；
  - ⚠️ **只看名字、不查存在**（撞名直接覆盖别人的文件）⇒ 撞名那条红（这条是最危险的改法，必须杀得死）；
  - 查错目录（拿 `process.cwd()` 当目标目录）⇒ 红；
  - 对照：加一行注释 ⇒ 全绿。

## ⚠️ 这是**用户可见的行为变化**（虽小）

- 好处：交付物名字干净。
- 不变的：**永不覆盖**（撞名时照样改成带随机后缀的名字）。
- 反悔成本：一个 `git revert`（`uniqueFileName` 还在，改回去只是把调用换回来）。
