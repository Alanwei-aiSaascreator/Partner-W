# 网关消失时说一句 —— 实施记录

**Goal:** 网关从本机消失（U 盘被拔、盘符变了、网关被移除）时，界面不再**静默**把用户换到另一个网关上。

**已拍的边界（用户 2026-09-24）**：**维持既有行为**（照旧自动切换），只**加一条说明**；
判据按 `gatewayInfoMap` 的**成员变化**，**不挂 `requestDeferred`** ——
否则正常换网关也会弹，而且可能闪。

**缺口在哪**：`useGatewaySelector` 的回落 effect 自己写着这句话 ——

> 用户**明确选过**的助手会被静默换掉、且没有任何提示。那是"网关没了"这个更上层的事件的
> 通知缺口，**属于另一件事**，已登记（见账本的"待拍"一节）。

## 做了什么

| 文件                                        | 内容                                                                                                                                                                   |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/renderer/lib/gateway-disappearance.ts` | `disappearedGateways(前一份, 这一份)` 纯函数 + `useGatewayDisappearanceNotice()`；挂在 `MainArea`（**进了工作区才报**：在登录页/引导页被切走，等回来时这句已经没意义） |
| `connection.gatewayDisappeared` × 9 locale  | 带 `{{name}}` 的一句话                                                                                                                                                 |
| `test/gateway-disappearance.test.tsx`       | 12 条：纯函数 7 + hook 4 + 启动顺序 1                                                                                                                                  |

判据的三条规矩（都钉了）：

1. **第一次观测不算**（`previous === null`）—— 那只是"刚看到地图"；少了它启动就弹假话。
2. **全没了不报** —— 那是另一种情况，`ConnectionBanner` 已经有「一个网关都没有」的横条 + 出口。
3. **只增不减不报** —— 新插一块盘不是"消失"。

出口取 **toast（warning 档，8 秒）**：不动布局、不拦操作、不需要新状态。
⚠️ **位置是产品选择** —— 本轮取最轻、最容易改回去的一种；要常驻横条的话说一声。

## 执行期发现

- ⚠️ **我的第一条变异是"等价变异"**：把 `if (previous === null) return []` 改成
  `previous = {}` —— 空对象进循环同样什么都找不到，改不出红（与 P2 那次 `docx`
  字体对象换成字符串是同一类错）。**这条守卫真正挡的是 `Object.entries(null)` 会抛**，
  删除整行才杀得死。教训：变异要改**行为**，不是改**写法**。
