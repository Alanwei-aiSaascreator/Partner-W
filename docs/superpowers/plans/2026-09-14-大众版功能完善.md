# Partner-W大众版功能完善计划

**日期：** 2026-09-14  
**产品目标：** 让第一次接触 AI 的普通用户，在登录后 3 分钟内明确产品能做什么、选好自己的主要用途，并完成一次真实 AI 任务。

## 一、需求依据

本计划融合以下材料，并以当前产品决策为准：

- 《AI-U盘-需求对齐》：身份动态架构、6–8 个角色、三栏对话、模型切换、积分支付、C 端使用概览。
- 《智能体新手引导与界面优化探讨》：避免空白首页，提供分步引导、标准任务示例和第一次实操。
- 老板游戏化 Demo：身份选择、新手村、工作台、使用数据与成长反馈。
- 当前冻结范围：暂停自动发现 `license.key`、一次性兑换 RPC、设备激活重构和 `max_activations` 重构。

## 二、首版产品主路径

```text
手机号登录
→ 首次用途设置（多选或自填）
→ 个性化首页
→ 选择罗盘助手或专业助手
→ 选择模型
→ 完成一次真实 AI 任务
→ 查看余额与使用记录
```

## 三、功能分层

### P0：大众版可用闭环

1. 手机号登录与账号恢复。
2. 首次用途设置：称呼、用途多选、自定义目标、跳过。
3. 个性化首页：根据用途排序快捷任务，自定义目标可直接继续。
4. 罗盘助手、新建对话、模型选择、真实回复。
5. 余额展示、额度提醒、充值入口和基础流水。
6. 首次任务成功反馈及下一步建议。

### P1：产品价值形成

1. 七个预置助手：罗盘助手、内容创作、拍摄剪辑、高效办公、电商运营、学习研究、生活家庭。
2. 每个助手具备独立身份说明、开场语、推荐任务和技能组合。
3. 用户用途资料同步到账号，换电脑登录后恢复。
4. 简化版“我的 AI 使用概览”：使用次数、常用助手、模型消耗、余额变化。
5. 新手引导可重新进入，支持修改用途。

### P2：后续扩展

1. 智能体市场、技能市场、需求悬赏和创作者中心。
2. 团队协作、定时任务、企业权限和运营后台深化。
3. 游戏等级、徽章、成长值及活动裂变。
4. U 盘自动发现和设备商业激活重构。

## 四、角色策略

首版不放“智能投资”作为大众默认角色。金融建议准确性和合规要求更高，待能力边界、提示语和审核机制明确后再上线。

| 助手     | 主要用户             | 首批能力                       |
| -------- | -------------------- | ------------------------------ |
| 罗盘助手 | 不确定该选什么的人   | 需求澄清、任务拆解、助手推荐   |
| 内容创作 | 自媒体和日常创作者   | 选题、结构、文案、改写         |
| 拍摄剪辑 | 短视频和产品拍摄用户 | 脚本、分镜、镜头清单、剪辑节奏 |
| 高效办公 | 职场用户             | 文档、表格、会议、汇报         |
| 电商运营 | 店主和运营人员       | 选品、竞品、商品文案、客服话术 |
| 学习研究 | 学生和知识工作者     | 资料整理、观点比较、学习计划   |
| 生活家庭 | 家庭用户             | 菜谱、出行、亲子活动、家庭计划 |

## 五、当前实施批次

本批次完成：

1. 首次用途设置页面。
2. 按账号区分的本地用途资料，数据结构预留云端同步版本号。
3. 首页根据用途排序快捷任务。
4. 自定义目标进入首页后可一键填入任务输入框。
5. 回归测试、类型检查、i18n 和生产构建。

本批次不创建云端 Agent，不修改数据库，不接触已暂停的 License 自动发现与设备激活重构。

## 六、验收标准

1. 新用户登录并完成基础设置后看到用途选择页。
2. 用户可选择多个用途，也可只填写自定义目标。
3. 用户可跳过，且同一账号下次启动不重复强制出现。
4. 首页前四个快捷任务会根据用途调整顺序。
5. 自定义目标会成为首页第一条可继续任务。
6. 点击任一快捷任务，输入框获得可编辑的任务说明，不自动发送。
7. 原有登录、余额、模型选择和真实回复路径不受影响。
