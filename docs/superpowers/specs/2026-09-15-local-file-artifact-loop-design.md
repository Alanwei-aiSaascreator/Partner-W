# Partner-W本地文件与成果交付闭环设计

**日期：** 2026-09-15

**状态：** 设计已获用户方向确认，等待用户审阅本文后进入实施计划

## 1. 目标

把现有分散的附件、上下文文件夹、工作区和成果能力组织成一条可演示、可恢复、权限清晰的真实 Agent 任务链路：用户在某个专业助手中主动选择本地资料，助手读取资料并调用已允许的工具完成任务，生成的真实文件自动进入当前任务成果区，用户可以打开、定位或另存成果，重启客户端后仍能继续查看。

首个验收故事固定为：进入“高效办公”助手，选择一个 Word、PDF 或 Excel 文件，要求整理并生成总结，看到简洁执行进度，获得一个真实成果文件，打开文件或所在目录，重启应用后仍能找到该任务与成果。

## 2. 现有基础

当前代码已经具备以下能力，本功能应复用而不是重写：

- 附件选择后复制到任务 `inbox`，并随消息发送给网关。
- 用户选择上下文文件夹、索引受支持文件、受目录范围约束地读取文件。
- 任务工作区、消息附件和成果记录使用本地 SQLite 与文件系统保存。
- Markdown 图片、代码块和部分网关附件可以自动提取为成果。
- 成果支持缩略图、列表、打开文件和在资源管理器中定位。
- 0 Token、未激活、许可证无效或额度核验失败时，发送和工具调用已经失败关闭。

当前主要缺口：上下文文件夹授权只保存在渲染进程内存中；主进程读取授权仍依赖渲染进程传入目录列表；文件与文件夹入口分散；非图片/代码类型的工具生成文件缺少稳定的成果登记；成果列表缺少直接操作与失效状态；助手欢迎页没有把资料、任务和成果串成明确流程。

## 3. 方案选择

采用“闭环增强”方案：保留现有附件、上下文读取、工作区和成果数据库，在其上增加主进程授权登记、任务级来源持久化、输出文件对账和统一成果卡片。

不采用只调整入口文案的轻量方案，因为它无法解决重启恢复、主进程授权可信度和工具生成文件漏记问题。也不采用全盘电脑 Agent 方案，因为整盘扫描和泛化系统控制会扩大隐私、安全与演示稳定性风险。

## 4. 用户流程

### 4.1 进入助手

每个内置专业助手保留独立欢迎页。欢迎页显示助手定位、三到四个示例任务和统一任务输入框。不同助手提供不同示例和提示词，底层复用同一套资料与成果能力。

### 4.2 添加资料

输入框“＋”菜单首层只保留用户能理解的两个入口：

1. `添加文件`：选择一个或多个文件，复制到当前任务 `inbox`。复制后的任务副本是本次任务的稳定输入；原文件随后移动或删除不影响已发送任务。
2. `添加文件夹`：授予当前任务对一个目录的只读访问。界面显示目录名称和路径，用户可随时移除。文件夹内容不整体复制，只在用户明确引用文件时读取。

文件和文件夹都显示在输入框上方的“本次任务资料”区域。发送前可以移除；发送后消息保留已使用资料的名称、类型和任务内副本信息。

### 4.3 执行任务

主聊天区只显示语义化进度：`读取资料`、`分析任务`、`生成成果`、`保存完成`。同一阶段内连续的 `ls`、`read`、`exec` 等原始工具调用合并，数量和技术明细放在可展开区域中。

如果助手只给出文本答复而没有创建用户要求的文件，界面不伪造成果卡片。只有任务工作区中实际存在且登记成功的文件才称为成果。

### 4.4 查看成果

新成果同时出现在回复下方和右侧成果区。卡片显示文件名、格式、大小、生成时间和状态，并提供：

- `打开文件`
- `打开所在目录`
- `另存为`

另存为必须使用 Windows 原生保存窗口。用户取消时不产生错误提示。目标已存在时由系统保存窗口确认是否覆盖，应用不静默覆盖。

### 4.5 重启恢复

任务、输入附件副本、文件夹授权和成果记录均从本地数据库恢复。恢复文件夹授权时先验证真实路径：

- 路径存在：显示“已授权”。
- 路径丢失或当前电脑不可用：显示“需要重新选择”，不自动寻找同名目录。
- 同一账号换电脑：同步的任务文本不得携带可直接使用的旧电脑授权；本地绝对路径和目录权限不上传云端。

## 5. 架构与边界

### 5.1 主进程授权服务

新增任务级上下文来源服务，主进程是授权真源。渲染进程不能再通过任意 `folders` 参数扩大读取范围。

服务负责：

- 通过 Electron 原生选择窗口创建文件夹授权。
- 按任务列出和撤销授权。
- 读取文件时使用 `taskId + sourceId + relativePath`，在主进程重新解析真实路径并验证仍位于授权目录内。
- 拒绝符号链接逃逸、目录穿越、已撤销授权和不存在路径。
- 限制目录深度、文件数量、单文件大小及支持格式。

本地 SQLite 新增 `task_context_sources`：`id`、`task_id`、`kind`、`absolute_path`、`display_name`、`created_at`、`last_seen_at`。首版 `kind` 仅为 `folder`。路径只存本机，不进入账号画像云同步。

### 5.2 输入副本服务

单文件继续复制到任务 `inbox`，但文件选择改由主进程完成，避免渲染进程依赖浏览器 `File` 对象和超大 base64 往返。主进程校验格式和大小后，以流式复制方式落盘并返回任务相对路径、名称、MIME 和大小。

首版输入格式：常见文本与代码、PNG/JPEG/WebP、PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX、CSV、JSON。压缩包不进入首个验收路径；可以继续作为普通附件保留，但不承诺自动展开和理解。

### 5.3 成果对账服务

保留现有消息自动提取逻辑，并新增任务输出对账：在一次助手运行结束后扫描当前任务成果目录，将本轮新建且未登记的文件写入 `artifacts`。`inbox` 输入副本必须排除，临时文件、隐藏文件、零字节未完成文件和仍在写入的文件必须排除。

对账使用任务、规范化相对路径、文件大小和修改时间生成稳定来源标识，重复同步或历史补载不得产生重复卡片。文件仍在写入时延迟一次有界重试；失败只影响成果登记，不把已经成功的模型回复改成失败。

### 5.4 展示层

新增可复用的 `TaskMaterials` 和 `ArtifactCard`，欢迎页、聊天输入区、消息回复和右侧成果区使用同一份状态与动作。现有体积较大的聊天输入组件只负责组合，不在其中继续堆叠授权数据库和文件对账逻辑。

## 6. 权限与隐私

- 不扫描整台电脑，不默认访问桌面、文档、下载或 U 盘其他目录。
- 文件夹授权只属于当前本地任务，用户可见、可移除。
- 单文件在用户选择后复制到任务工作区；界面明确提示“任务将使用工作区副本”。
- 默认成果只写入Partner-W工作区。写入工作区外位置仅通过用户主动点击“另存为”完成。
- 路径和文件内容不写入遥测日志；错误日志仅记录错误类别、文件类型、大小区间和请求标识。
- 0 Token 或商业授权失败时允许管理本地资料和打开既有成果，但禁止向模型发送资料、启动新运行或调用电脑工具。

## 7. 异常处理

- 输入文件超过限制：发送前指出具体文件及限制，不丢弃其他已选资料。
- 格式不支持：保留在界面并标记“当前不能读取”，不假装已交给助手。
- 文件夹权限被撤销或路径消失：显示“需要重新选择”，引用时阻止发送该文件。
- 成果文件被外部删除：卡片保留历史记录并显示“文件已不在本机”，允许从列表移除记录。
- 打开文件失败：保留成果卡片，显示可理解的错误并继续提供“打开所在目录”。
- 网关中断：已复制的输入和已生成的成果不回滚；任务可在连接恢复后重试。

## 8. 测试与验收

### 8.1 自动化测试

- 主进程授权服务：创建、列出、撤销、重启恢复、目录穿越、符号链接逃逸和路径失效。
- 输入副本：多文件、重名、安全文件名、大小限制、取消选择和复制失败。
- 成果对账：发现新文件、排除 `inbox`/临时文件、重复对账、写入中重试和外部删除。
- 发送守卫：0 Token、未激活、许可证失效和额度核验失败时不发送文件、不调用模型或工具。
- UI：资料标签、失效状态、四阶段聚合进度、成果卡片三个动作和重启恢复。
- 现有全仓测试、Desktop 测试、类型检查、i18n 检查、架构检查和生产构建继续通过。

### 8.2 实机验收

在源码态和最新 Windows 安装包各完成一次：

1. 使用高效办公助手选择 Word、PDF 或 Excel 文件。
2. 要求助手生成一份真实总结文件。
3. 确认页面没有铺满原始工具调用。
4. 打开成果文件、打开所在目录并另存到用户选择的位置。
5. 退出并重启，确认任务、文件夹授权状态和成果卡片恢复。
6. 删除或移动一个外部授权目录，确认应用显示失效而不是崩溃。
7. 使用 0 Token 账号确认只能管理本地资料和既有成果，不能启动新的 AI 或工具任务。

## 9. 本期不做

- 整盘扫描、后台自动发现用户文件或永久系统级文件权限。
- 将本地绝对路径或原始文件自动同步到云端。
- 自动修改 U 盘中的原始安装包或用户源文件。
- 压缩包自动解压、OCR 全格式覆盖、多人实时协作和成果在线分享。
- 团队、市场、悬赏、广场、创作者中心和游戏化模块。

## 10. 完成标准

只有同时满足以下条件才算完成：用户无需开发命令即可从专业助手添加真实资料；主进程严格执行可见授权边界；助手能够生成至少一种真实可打开的成果文件；成果卡片三个动作可用；重启后任务与成果恢复；0 Token 和未激活状态不能借文件或工具路径绕过商业守卫；最新 Windows 安装包完成全新环境彩排。
