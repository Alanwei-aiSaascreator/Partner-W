# 账号额度隔离与电脑工具授权设计

**日期：** 2026-09-15  
**范围：** 荣盈魔方桌面端商业模型发送门禁、账号切换隔离、工作区权限说明

## 目标

修复“新账号显示额度待开通但仍可正常聊天”的 P0 问题，确保商业模型能力只属于当前登录账号；同时把文件权限说明改为符合真实 Agent 能力的授权口径。

## 已确认根因

1. `evaluateQuota(0, 0)` 当前返回 `unlimited`，而无许可证和额度未开通也会传入 `0`，导致发送端主动放行。
2. 退出登录只清理商业登录会话，没有移除本机网关中的旧商业中转 provider 与密钥。
3. 新账号没有许可证时，启动引导返回 `unlicensed`，但旧 provider 仍留在网关配置和模型目录中，因此旧账号能力可被新会话继续使用。

## 授权与额度规则

- 没有商业账号快照、账号快照读取失败、没有许可证、许可证未激活、总额度小于等于零或余额耗尽时，商业模型发送默认拒绝。
- 数字 `0` 只表示未开通或没有可用额度，不再表示无限额度。
- 未来若提供无限套餐，服务端必须返回独立、明确的无限额度字段；客户端不得从数值猜测无限资格。
- 发送前使用当前商业账号快照重新判定，不以界面是否显示模型作为授权依据。
- 服务端仍是最终计费与授权真源；客户端门禁用于避免错误体验和旧凭证误用，不能替代服务端校验。

## 账号切换隔离

- 退出登录成功后，清除本地保存的许可证键。
- 从网关配置中移除所有指向荣盈商业中转地址的 provider、相关插件允许项和由该 provider 产生的默认模型引用。
- 清理后刷新模型目录；无许可证的新账号不得看到或调用上一个账号留下的商业模型。
- 登录新账号后，仅在确认当前账号拥有有效许可证并取得当前账号中转凭证后，重新配置商业 provider。
- 清理过程必须幂等；重复退出、网关未连接或 provider 已不存在时不得造成崩溃。
- 网关暂未连接时记录待清理状态，并在网关连接后优先完成清理，再允许商业模型进入可用状态。

## 用户界面

文件与电脑工具说明统一为：

> 助手默认查看当前工作区和你主动添加的文件。需要访问电脑其他位置、调用电脑工具或保存文件到指定位置时，会先说明操作内容并由你确认。

额度状态规则：

- 无许可证或总额度为零：显示“额度尚未开通，请先激活”，发送按钮不可执行商业模型请求。
- 额度读取中：显示正在核验，不允许发送。
- 额度读取失败：显示刷新入口，不把失败降级为无限额度。
- 余额耗尽：沿用现有额度耗尽提示。

## 测试与验收

必须先增加失败测试，再修改实现：

1. 无许可证时发送被阻止。
2. `tokenQuotaMicros = 0` 时发送被阻止。
3. 额度快照未读取或读取失败时发送被阻止。
4. 明确有余额时保持现有发送流程。
5. 退出登录会清除本地许可证并移除商业 provider。
6. “旧账号有额度 → 退出 → 新账号无额度”时，新账号看不到旧商业模型且无法发送。
7. 网关未连接时退出，后续连接仍会完成待清理操作。
8. 新权限文案通过界面文案和国际化检查。
