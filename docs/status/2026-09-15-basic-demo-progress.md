## 四、短期 Demo 应呈现的完整故事

演示时只讲一条容易理解的价值链：

```text
插入Partner-W U 盘并启动客户端
→ 手机号登录
→ 选择“我想用它做什么”
→ 输入随 U 盘提供的激活码
→ 系统准备 AI 服务、模型和七个内置助手
→ 选择一个助手的专业任务模板，或直接描述任务
→ 选择模型并获得真实结果
→ 在使用概览中看到余额和本次实际消耗
→ 退出后在另一台电脑登录同一账号仍可继续使用
```

首场建议用“拍摄剪辑”或“内容创作”作为任务示例。例如用户输入一段产品资料，让助手生成短视频脚本、镜头清单和发布文案。这个场景能同时展示用途引导、专业助手、真实模型、连续修改和成果输出，比单纯问答更像一个可售卖产品。
