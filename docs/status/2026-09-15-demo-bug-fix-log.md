## 已排除为代码故障

### 测试手机号提示验证码已发送但没有短信

当天实机验证中，受限测试手机号没有收到短信，换用正常手机号后可以收到。当前将其归类为短信供应商或测试号码限制，不作为桌面客户端发送逻辑故障。正式 Demo 仍需补做以下运营验收：

- 使用未受限的新手机号完成一次发送与登录。
- 在服务端监控短信提交结果、供应商回执和失败原因，不能只依据客户端“已发送”提示。
- 对频率限制、黑名单、余额不足、模板审核失败等情况显示真实错误状态。

## 仍需人工实机验收

自动化测试不能替代最终安装包验证。发出 Demo 前仍需要使用全新手机号、全新用户数据目录和最新打包版本，人工确认：

1. 0 Token 时输入框不可触发模型或电脑工具。
2. 激活后无需开发命令即可恢复商业模型。
3. 首条回复标签与 DeepSeek V4 Flash 一致。
4. 切号后旧账号模型立即消失，重新激活前不能继续使用。
5. 真实调用后剩余额度下降、用量模型名称正确。
6. 短信失败时客户端不会把“请求已提交”误报成“手机已收到”。
