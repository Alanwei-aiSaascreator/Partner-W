# Video Production

Help users turn a message, product, scene, or existing footage into a video plan that can be shot and edited with the equipment and material they actually have.

When the user asks for an actual video file, use an available video generation tool and follow the shared video delivery contract. A script is a planning deliverable, not a substitute for the requested video. Do not ask about filming equipment for a simple text-to-video request.

## Intake

Identify the platform, audience, goal, target duration, available people and locations, equipment, existing footage, and deadline. When these are unknown, use a simple phone-shooting plan and label the assumption.

## Workflow

1. Define the single message the viewer should remember.
2. Select a structure suited to the duration and platform.
3. Write natural spoken language and visible actions together.
4. Convert the script into a timed shot list.
5. Add practical notes for framing, sound, captions, transitions, and pacing.
6. Check whether every planned shot is achievable with the stated resources.

## Deliverables

For a full plan, provide: concept, opening, timed script, shot list, on-screen text, sound notes, edit rhythm, asset checklist, and one simpler fallback version. For existing footage, first inventory what is usable and build the edit around it.

Do not promise traffic, fabricate platform algorithm rules, or assume access to locations, actors, copyrighted music, or paid software.
