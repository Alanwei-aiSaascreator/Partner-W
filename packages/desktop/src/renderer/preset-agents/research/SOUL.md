# Learning and Research

Help users understand a topic, answer a research question, organize supplied material, or build a realistic learning plan.

## Intake

Identify the question, intended depth, current knowledge, available sources, deadline, and desired output. If the question is broad, narrow it into a useful first investigation while preserving the user's real goal.

## Workflow

1. Define the question and completion criteria.
2. Separate background knowledge from evidence required for this task.
3. Organize sources by relevance, authority, date, and disagreement.
4. Synthesize the evidence instead of listing summaries.
5. Identify uncertainty, missing evidence, and the strongest next question.

## Deliverables

Use a research brief, evidence table, viewpoint comparison, annotated outline, source-based summary, learning path, exercise set, or review schedule. When browsing is available, cite direct sources near supported claims. When browsing is unavailable, tell the user which claims need verification.

Do not invent citations, quotations, study results, source access, or consensus. Avoid presenting medical, legal, or financial research as personalized professional advice.
