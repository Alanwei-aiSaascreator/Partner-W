# 周报撰写

周报的作用**不是证明你忙**，而是让读的人三十秒内知道：进度到哪了、卡在哪、下一步谁做什么。

## 先分桶，再动笔

把这一周的材料按**结果**分桶，**按事情分，不按天分**（按天写就是流水账）：

| 桶         | 判据                                       | 去处                             |
| ---------- | ------------------------------------------ | -------------------------------- |
| **做完了** | 有可检验的结果（"上线了""签了""发出去了"） | 「本周完成」                     |
| **在做**   | 起了头、还没有结果                         | 「进行中」+ **进度百分比或阶段** |
| **卡住了** | 等别人 / 缺信息 / 有依赖                   | 「需要支持」+ **明确要谁做什么** |
| **下周**   | 已经定了要做的事                           | 「下周计划」                     |

⚠️ **「卡住了」这一桶最容易空**。如果这一周一件卡住的事都没有，通常不是真的顺利，
而是你没问出来 —— 回头看一眼材料里有没有"等回复""还没定""看情况"这类词。

## 输出的固定形状

```markdown
# 周报（<起止日期>）

## 本周完成

- <结果> —— <如果这是一件大事，一行讲清影响>

## 进行中

- <事项>（<进度：阶段/百分比>）

## 需要支持

- <卡点> —— 需要 <谁> 做 <什么>，<期望时间>

## 下周计划

- <事项> —— <目标结果>

## 数据（有就填，没有就整节删掉）

| 指标 | 本周 | 上周 | 变化 |
| ---- | ---- | ---- | ---- |
```

## 硬规则

- **写结果，不写动作**。"对接了客户"是动作，"客户确认了报价，下周三签"是结果。
  材料里只有动作的，照实写成进行中，**不要**替它编一个结果。
- **没有数字就不要用程度词**。"大幅提升""效果很好"这类词一律不写；
  有数字就写数字，没数字就写发生了什么。
- **不编造进度百分比**。材料里没说，就写阶段（"方案已定、待排期"），不要写"70%"。
- **需要支持那一节必须点名**。"希望得到支持"不是一条信息，
  "需要张三在周三前确认预算"才是。
- **空桶就删掉整节**，不要留一个只有标题的空壳 —— 那会让读的人以为漏看了。

## 材料太少时

少于三五件事：直接说"这一周的可写事项不足，要写成周报还需要补充 X/Y"，
不要用形容词把一段话撑成一份周报。
