# 发布前核验清单

## 先确定范围
收集服务/版本、候选提交、环境、计划日期、负责人、变更列表、依赖、已知风险。区分功能开关、数据库迁移和破坏性 API 变更；涉及消费者时准备通知草稿。
本技能的“发布阶段”是供获授权发布者执行的清单，不是执行部署、通知或修改生产的指令。没有证据的项保持未勾选；每次发布都重新核对，不沿用上次的绿勾。

## 发布前
- 测试与 CI：记录实际运行、环境、时间和结果；未跑不记通过。
- 审查与批准：核对确切候选的审查记录，列出阻断缺陷。
- 数据库迁移：列出测试证据、兼容性、数据保护及回滚限制。
- 功能开关：列出目标值、依赖、默认行为和验证方法。
- 回滚计划：前置条件、执行负责人、恢复检查、不可逆风险。
- 值班通知：列出需要知会的人及待发送草稿，不自动发送。

## 发布阶段（建议清单）
- 在授权测试环境部署并核验候选；执行者记录事实。
- 冒烟与关键用户流程验证，明确预期和失败条件。
- 生产发布建议（适用时金丝雀），列明是否已获独立授权。
- 错误率与延迟观察建议：原流程参考15分钟，实际窗口根据系统约定确定，不自动建立后台监控。
- 关键用户路径、数据完整性及授权范围内的验证证据。

## 发布后（建议清单）
- 核实指标恢复/正常，记录时间与观察范围。
- 准备发布说明与变更日志草稿。
- 准备利益相关方通知及关联工单关闭建议；未经授权不外发、不关单。
- 剩余异常、后续负责人、观察截止条件。

## 回滚判据
列出错误率超过 X%、P50 延迟超过 X ms、关键用户流程失败等触发条件。X 必须来自已核实基线和团队约定；未知阈值写“待确认”，不要凭空填数。列出谁判断、谁执行、如何确认恢复。
有迁移时额外说明回滚是否可逆、数据是否需要向前修复；破坏性 API 列消费者兼容方案；功能开关列关闭后的行为。

## 输出
服务/版本、日期、负责人 + 分阶段未完成/通过/失败/NOT RUN清单 + 证据 + 回滚阈值表。连接器仅在现有授权可读时用于核对差异、CI与监控基线，不能替代发布授权。

## 执行与交付边界
不改变现有权限、工具审批、工作区和文件产物合同。技能是工作流程，不是额外工具、连接或执行授权；只使用当前实际可用且在任务授权范围内的工具与资料。没有连接器时使用本地或用户提供的材料，不宣称平台已接通。
发布、部署、生产处置与对外通知仅输出建议清单或草稿；本技能不默许执行，也不自动创建工单、通知他人或后台监控。实际执行须由获授权的流程另行处理。
需要文件交付时沿现有能力生成并写入允许位置，校验 → 登记 artifact → 用户能打开 才算成功；未保存的文本称草稿，未跑的验证标 NOT RUN，不虚报完成。
