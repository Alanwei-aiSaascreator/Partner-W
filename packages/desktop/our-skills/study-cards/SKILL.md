# 学习卡片

目标不是把原文缩短，是**把"读过了"变成"答得出来"**。
所以每张卡片的背面必须是一个**能自测的答案**，而不是一句概括。

## 步骤

### 1. 先出提纲（三层以内）

```
一、<主题>
    1.1 <要点>
        1.1.1 <细节>
```

提纲的作用是**暴露结构**：原文如果没有结构（很多课程资料是散点），
就把相关的点聚在一起，并在末尾说明"原文是散点，我按 X 归的类"。

### 2. 再出卡片

每张：

```markdown
**Q：<问题>**
A：<答案>
（出处：原文第 <位置> 段 / <小节名>）
```

⚠️ 卡片问题的写法决定卡片有没有用：

| 差的问题      | 好的问题                         |
| ------------- | -------------------------------- |
| 什么是 XX？   | XX 和 YY 的区别是什么？          |
| 讲一下 XX     | 什么情况下**不该**用 XX？        |
| XX 有几个特点 | XX 的第 3 个特点解决了什么问题？ |

**能靠"背名词"答出来的问题一律重写。**

### 3. 卡片分三级

- **必会**（答不出来后面看不懂）
- **会用**（知道什么时候用、什么时候不用）
- **知道**（听过即可，不用背）

在每张卡后面标上级别。一堆不分级的卡片等于没有重点。

## 硬规则

- **只写原文有的**。答案必须能在原文里指到出处。
  原文含糊的地方，卡片里也含糊 —— 并在末尾的「空白」一节列出来。
- **不编造出处**。指不到具体位置的，写「出处：原文中未明确定位」，
  **不要**编一个段落号。
- **不把"我的理解"当"原文说的"**。需要引申时单独用
  `💡 我的补充（不是原文）：…` 标出来。
- **末尾必须有一节「⚠️ 原文没讲清的」**：前后矛盾的地方、跳过的推导、
  给了结论没给条件的地方。这一节往往比卡片本身更有价值。
- 原文很长时**先问要覆盖哪部分**，不要一口气抽 200 张卡片 —— 那样等于没抽。

## 输出顺序

提纲 → 卡片（按级别分组）→ ⚠️ 原文没讲清的 → 一共 N 张（必会 X / 会用 Y / 知道 Z）
