# 幻灯版面（自己排）

要**拿给人看**、而且**内容不想被固定格子限制**的演示文稿，用这条路。

## 它和另外两条的区别

|                        | 怎么排的                       | 你受什么限制                                                            |
| ---------------------- | ------------------------------ | ----------------------------------------------------------------------- |
| 「文档生成」           | 客户端画白底 + 标题 + 项目符号 | 只能这样，**没有版式**                                                  |
| 「商务演示（模板版）」 | **填格子**进设计师做好的版     | **每格有字数上限** —— 写长了整份被拒                                    |
| **这条路**             | **你自己写版面**（CSS 布局）   | 单份上限 **1 MiB / 60 页**；⚠️ 且**必须写成文件**，贴进回复正文会被截断 |

⚠️ 如果你要放的内容**很多**（一页十几条、每条几十字），走这条路；塞进固定格子会被拒。
反过来，**随手记点东西**别用它 —— 写版面比填格子慢。

## ⭐ 整份版面**写成一个文件**，不是写进回复

把整份源码**用写文件工具写到工作区里的一个文件**，文件名以 `.slidegen` 结尾，例如
`九月经营简报.slidegen`。客户端读的是**这个文件**，不是聊天里的字。

⚠️ **不要**把整份源码贴进回复正文。回复正文有一个**很紧的长度上限**，
贴进去会被截断，而截断之后**整份都作废** —— 用户什么都拿不到。
文件没有这个上限。

- 文件**内容**照旧是**一个** `slidegen` 围栏块（就是要你平时放进回复的那种），
  **围栏必须闭合**。客户端按围栏取源码，缺了结尾围栏就取不出来。
  ⚠️ 开头与结尾那两行 ` ``` ` 都要**单独占一行** ——
  结尾的 ` ``` ` 若黏在 `</Slide>` 后面（写成 `</Slide>````），
  客户端就**认不出围栏已经结束**，会当作"没写完"而整份丢掉。
- **一次写完**，别分两个文件、也别为了变短停在一半。
- 回复正文里**只留一句短说明**：做完了 / 文件在哪 / 大概几页。**不要复述源码。**

> 为什么这样：真机上"整份写进回复"**连续四次**都因为超过上限被截断而失败；
> 而同一次**写进文件的那份是完整的**（13 KB）。

⚠️ **一栅最多 60 页**（`SLIDEGEN_MAX_PAGES`）。整册内容很多时请自己拆成几份，
不要一份写到 60 页以上 —— 超了整份不会生成。

## ⚠️ 版面写紧凑（默认就这么写）

源码越短，排版越快、越不容易出问题。默认按紧凑写法，**不要**写讲稿式的长段落：

- **一页只说一页的事**：标题 + 三到六条要点，每条一两行就够。成段的讲稿留给备注或另开一份文档。
- **CSS 别重复**：能写在 `<Slide>` 上就别每页复制一遍；同样的字号 / 颜色 / 间距**抽成一处**，
  不要每个元素都内联写满。重复的样式是源码里最占体积、也最容易写错的部分。
- **别堆装饰**：一条整页的渐变 + 十几个绝对定位的装饰块，观感收益很小、体积代价很大。
- **单页文字控制住**：一页塞进几百字，投影出来没人看得清，而且很容易溢出。

> 内容真的很多（一份完整课件的讲稿式内容）时：**先把结构列成要点**，
> 再按上面的紧凑写法排 —— 而不是把讲稿原文整段搬进版面。

## 怎么写

文件**里面**放**一个**围栏代码块，语言标记是小写 `slidegen`，内容是 **JSX 版面源码**：

````
```slidegen
// title: 九月经营简报
<Slide style={{ width: 1280, height: 720, background: '#FFFFFF', position: 'relative' }}>
  <Text style={{ position: 'absolute', left: 80, top: 60, width: 900, fontSize: 40, fontWeight: 'bold', color: '#100D13' }}>
    九月经营简报
  </Text>
</Slide>
```
````

**第一行必须是 `// title: 文件名`** —— 它是这份文件的**名字**，漏了整份会被拒。
一个围栏里可以并列**多个 `<Slide>`**，那就是多页（最多 60 页）。

## 只有四个标签

| 标签    | 是什么       | 说明                                                               |
| ------- | ------------ | ------------------------------------------------------------------ |
| `Slide` | 一页（画布） | **必须是 1280×720**，且要有 `background`                           |
| `Box`   | 容器         | **自动是 flex 容器**，用 `flexDirection` / `gap` / `alignItems` 排 |
| `Text`  | 一段文字     | 直接写内容，或 `{表达式}`                                          |
| `Image` | 图片         | `src="assets/xxx.png"` —— **只能引用工作区里已有的图**             |

别的标签（含 `div`、`span`、`h1`）**一律被拒**。这是个封闭集合，不是"尽量兼容"。

## 样式就写 CSS（用 JS 对象的样子）

`style={{ 属性: 值 }}`，属性用驼峰（`fontSize`、`flexDirection`、`borderRadius`）。

- **数值默认是 px**（`width: 548` → 548px）。少数不带单位的：`fontWeight`、`lineHeight`、`opacity`。
- **颜色**写 `'#RRGGBB'`；渐变写 `'linear-gradient(90deg, #7A1CA8 0%, #D92179 50%, #FF7A29 100%)'`。
- **能在 CSS 里表达的，基本都支持**：`position: 'absolute'` + `left/top`、flex（`flexDirection` / `gap` / `justifyContent` / `alignItems`）、`borderRadius`、`border: '1px solid #ECE9F0'`、`padding`、`letterSpacing`。

⚠️ **渐变文字**这么写（会渲染成真的逐字渐变）：
`backgroundImage: 'linear-gradient(...)', backgroundClip: 'text', color: 'transparent'`

## 可以写 JavaScript

里面的 `{}` 是**真的 JS**，所以**列表用 `.map()` 展开**，不要手抄 N 遍：

````
```slidegen
// title: 三阶段落地节奏
<Slide style={{ width: 1280, height: 720, background: '#FBFBFD', position: 'relative' }}>
  <Box style={{ position: 'absolute', left: 80, top: 150, width: 1120, flexDirection: 'row', gap: 20 }}>
    {[
      ['Phase 01', '0 - 1 个月', '启动筑基期'],
      ['Phase 02', '1 - 2 个月', '现金流爬坡期'],
      ['Phase 03', '2 - 3 个月', '全域盈利期'],
    ].map((it, i) => (
      <Box key={i} style={{ width: 360, flexDirection: 'column', gap: 10, padding: '20px', borderRadius: 14, background: '#FFFFFF', border: '1px solid #ECE9F0' }}>
        <Text style={{ fontSize: 15, color: '#7A1CA8', fontWeight: 600 }}>{it[0]}</Text>
        <Text style={{ fontSize: 30, fontWeight: 'bold', color: '#100D13' }}>{it[1]}</Text>
        <Text style={{ fontSize: 18, color: '#4A4356' }}>{it[2]}</Text>
      </Box>
    ))}
  </Box>
</Slide>
```
````

## 版式纪律（这是"好看"的全部来源）

**一页三块，位置钉死**（1280×720）：

| 区       | 范围                | 放什么                                      |
| -------- | ------------------- | ------------------------------------------- |
| 顶部彩条 | `top: 0, height: 5` | 品牌三色渐变，每页都有                      |
| 标题块   | `top: 44` 起        | 主标题 34px bold + 副标题 17px 灰           |
| 内容区   | `top: 130` 起       | 卡片 / 列表 / 图表                          |
| 页脚     | `top: 654`          | 左 logo + 中间方案名 + 右 `NN / 总数`，14px |

**左右留白 80px**（内容宽 1120）。封面 / 章节页 / 尾页可以不要标题块。

**几条让页面不土的规矩**：

- **标题写结论**，不写"关于……的说明"
- **一页只讲一件事**；装不下就**拆成两页**，别把字缩小硬塞
- 用**大数字**、色块、留白做视觉锚点；**不要用 emoji**、不要用花哨插画
- 正文 15–17px、卡片标题 22px、大标题 34px —— 层级靠**字号差**，不靠加粗堆叠

## 客户端会告诉你的两件事

**❌ 整份没生成**（提示里会说原因）：

- `// title:` 漏了 / 标签写错 / 版面语法错 / 表达式算不出来
- 看到提示就**按它说的改**，重新输出一次即可

**⚠️ 生成了，但有几处要调整**（**文件已经在产物里了**）：

- **内容超出画面** ⇒ 那一块放映时看不到。改法：**拆页**、缩内容、或调 `top` / `height`
- **文字被别的元素盖住** ⇒ 用户看不到那句话。改法：挪开盖住它的那块

⚠️ 这两种都**不会**让文件消失 —— 但用户会看到一句提示。**主动按上面两条自查一遍**
（内容别超出 720 高、`position:'absolute'` 的块之间别重叠），比事后被提示更省事。

## 说给用户的话

文件是**客户端在这一轮结束后**生成的：

- ✅ 可以说：「版面我排好了，稍后出现在**右侧「产物」**里，点开就是 .pptx，**里面的字可以直接改**。」
- ❌ 不要说「已经生成了」「文件在你桌面上」—— 那一刻文件还不存在。
- ✅ 用户要改哪一页，**你改那一页的版面重发一份**即可（他能看到全文，改起来是直达的）。

## 什么时候不要用它

- 用户要的是**随手草稿**、不在乎版式 ⇒ 用「文档生成」，快得多。
- 用户要**填一份现成的设计模板** ⇒ 用「商务演示（模板版）」。
- 用户要 **Word / Excel / PDF** ⇒ 那是「文档生成」的事。
- 用户要**网页** ⇒ 那是「网页交付」的事。
- 用户要**图片**（照片、插画）⇒ 做不到，别拿 `Image` 顶替 —— 它只能引用工作区里**已经存在**的图。
