# 会议纪要整理

把一段**口语化、跳跃、没头没尾**的会议记录，整理成**别人不用开会也能接着干活**的纪要。

## 先做这一步：分清三类内容

通读材料，把每一句归到下面三类之一。这是本技能的核心动作 ——
**没分清就开始写，出来的必然是流水账**。

| 类型     | 特征                                    | 去处         |
| -------- | --------------------------------------- | ------------ |
| **决议** | 已经拍板、有明确结论（"就按 A 方案做"） | 「已定事项」 |
| **待办** | 有动作、有归属（"你下周把报价发我"）    | 「待办」表   |
| **悬置** | 提了但没结论、没人认领、或明显分歧      | 「待确认」   |

⚠️ **最容易漏的是第三类**。口语里"这个回头再说""我们再看看"听起来像废话，
但它恰恰是**下次开会要接着吵的事** —— 漏掉它，纪要就变成了粉饰太平。

## 输出的固定形状

```markdown
## 会议纪要：<主题>

**时间**：<有就填，没有写「未记录」> ｜ **参与人**：<有就填>

### 一、已定事项

- <结论>（<依据/理由，材料里说了才写>）

### 二、待办

| 事项 | 责任人 | 时间 | 备注 |
| ---- | ------ | ---- | ---- |
| ...  | ...    | ...  | ...  |

### 三、待确认（会上没结论）

- <悬置的事> —— 卡在哪：<分歧点 / 缺的信息 / 等谁拍板>

### 四、关键信息（供存档）

<只有查历史时才有用的事实：数字、日期、外部约束>
```

## 硬规则

- **不编造责任人**。材料里没说是谁，就写「未指定」，**不要**按"这像谁的业务"去猜 ——
  猜错一次，纪要就没人信了。
- **不编造时间**。没提就留空，不要写成"下周"这种由你推算出来的相对时间。
- **保留原话里的数字与专有名词**（金额、型号、公司名、日期）。转写常有错别字，
  但**不要去纠正你不确定的专有名词** —— 在末尾加一句「⚠️ 以下词可能有转写误差：…」更安全。
- **不写评价**。不出现"会议气氛热烈""大家积极讨论"这类填充话。
- **不确定是不是决议的，归到「待确认」**。宁可多一条待确认，也不要把没定的事写成定了。

## 材料不完整时

- 材料太短（不足几句话）：直接说"这段材料不足以形成纪要"，并**列出你缺什么**，
  不要硬凑出一份结构完整的空壳。
- 材料是纯录音转写、有明显的说话人混杂：先按内容切段，
  在「待确认」里标一句"说话人未能区分"。
