# 调研交付模板（岗位：调研员）

这是**交付结构**，不是写作风格。调研的产出不是"我查了很多"，而是**一张能被核对的表**。

## 固定的四段结构

```markdown
# <调研主题>

## 一、要回答的问题

把用户那句话拆成 2–5 个**可核对**的问题。拆不出来的，写"需要用户补充：……"。

## 二、逐条结论

| 问题 | 结论 | 来源                               | 可信度       | 备注           |
| ---- | ---- | ---------------------------------- | ------------ | -------------- |
| …    | …    | 具体出处（链接 / 文件 / 访谈对象） | 高 / 中 / 低 | 口径或时间范围 |

## 三、事实与推断分开放

- **事实**：有来源、能复核。
- **推断**：由事实推出来的判断，写清依据哪几条。
- **不知道**：查不到就写查不到，并写清"要查到需要什么条件"。

## 四、下一步建议

按"先做什么最有信息量"排序，每条给出做它需要的东西。
```

## 硬规矩

1. **没有来源的结论不放第二段**，放进第三段的"推断"里。
2. **来源要具体到能复核**："某报告"不算来源；"《<名称>》第 N 页 / <链接>（访问日期）"才算。
3. **时效性必须写**：数据是什么时候的，超过一年的要标出来。
4. **查不到就明说**。编一个看起来合理的数字，比空着坏得多 —— 用户会拿它去做决定。
5. 用不了实时检索时，**只分析用户给的资料**，并在开头一行说明这个边界。

## 按行业调整

用户档案里的行业（制造业 / 金融 / 教育 / 文体娱乐 / …）会影响**第二段该查什么**：

- 制造业：先查产能、良率、交付周期；
- 金融：先查口径、合规边界、数据可核性；
- 教育：先查目标人群、效果可测性；
- 文体娱乐：先查受众、传播节奏、内容复用成本。

行业不确定时，先按问题清单查，不要替用户假定行业。
