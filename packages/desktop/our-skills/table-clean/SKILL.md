# 表格数据整理

原料通常是**从聊天记录、网页、截图里抄出来的**：列对不齐、格式不统一、有重复、有缺。
目标是给出一张能直接粘进 Excel 的干净表，**并且说清你动了什么**。

## 五步，按顺序做

### 1. 先定列

从数据里**推断**列名，然后**把推断说出来**：

> 我按这五列整理：姓名 / 电话 / 公司 / 金额 / 日期。如果不合你的意图，告诉我怎么改。

⚠️ 列名拿不准时**问**，不要悄悄把两列合并 —— 合错了后面全废，而且看不出来。

### 2. 对齐

每一行的字段按语义归位（**不是**按位置硬切）。行里少一个字段、多一个字段都要能处理。

### 3. 统一格式（只做**不会改变含义**的统一）

允许：日期统一成 `YYYY-MM-DD`；金额去掉千分位与货币符号但**保留两位小数**；
电话号码去掉空格与横杠；首尾空格；全角转半角。

**不允许**（这些会改变含义，只能标注、不能改）：

- 猜省份/城市补全地址
- 把简称补成全称
- 改单位（"3千" → 3000 可以，`3k` → `3000` 要标注）
- 修正看起来像笔误的数字

### 4. 去重

判定"重复"必须**给依据**。默认按**完全相同的整行**判。
只有用户说了"按手机号去重"之类，才按单列判。
⚠️ 姓名相同**不是**重复 —— 重名太常见。

### 5. 标出可疑行

放进表尾的「⚠️ 待确认」，**不要**直接改：

| 行  | 问题                       | 原文         |
| --- | -------------------------- | ------------ |
| 7   | 金额缺单位                 | `500`        |
| 12  | 日期疑似笔误（2023-02-30） | `2023/2/30`  |
| 19  | 电话位数不对（10 位）      | `1380013800` |

## 输出

1. **规范表格**（Markdown 表格；用户要 Excel 就给 TSV，用制表符分隔，能直接粘）
2. **改动清单**：每一条写 `原值 → 新值（理由）`
3. **⚠️ 待确认**：见上表
4. **一行统计**：共 N 行，去重 M 行，待确认 K 行

## 硬规则

- **原文存档**：改动清单里必须能看出**原来是**什么。只给结果不给原值，
  用户就没法核对，错了也发现不了。
- **不填补缺失值**。空着就空着，或用「（空）」占位，**不要**用均值/上一条/推算填。
- **不排序**。除非用户要求 —— 排序会让人对不上原始顺序。
- 数据里有**身份证号、银行卡号**这类敏感字段时，输出里**默认打码**
  （保留前 3 后 2），并说明"已打码，需要明文请告诉我"。别主动把它们完整复述一遍。
