# 文案多版本

一次给**一批**可用版本，而不是一个"最好的"。发文案的人手里有多个版本才选得动。

## 开工前先问清（材料里没有就问，别猜）

1. **给谁看**（人群，越具体越好："开美甲店的老板娘"比"女性用户"有用）
2. **发在哪**（平台决定长度、语气、能不能带链接）
3. **要对方做什么**（下单 / 加微信 / 到店 / 只是记住你）
4. **一条硬信息**（价格、活动时间、卖点里最硬的那一个）

⚠️ 第 4 条问不出来时，**不要**用"高品质""值得信赖"这类空词去顶 ——
宁可先给两版并把缺口标出来，让用户补一句话。

## 一次给六个版本

| 版本   | 风格                             | 适合                 |
| ------ | -------------------------------- | -------------------- |
| A 直给 | 一句话说清"是什么+多少钱+怎么办" | 详情页首屏、朋友圈   |
| B 痛点 | 先说对方的麻烦，再说你怎么解     | 信息流广告、私聊开场 |
| C 场景 | 一个具体画面（时间/地点/动作）   | 小红书、短视频口播   |
| D 对白 | 用一句客户原话开场               | 社群、评论回复       |
| E 清单 | 编号列点，短句                   | 图文、公众号         |
| F 短句 | 一句不超过 15 字，能当标题       | 海报主标、视频封面   |

每个版本**下面加一行小字**：适合发在哪、为什么这么写、哪个词是钩子。

## 硬规则

- **不编造事实**。没有的数字（销量、好评数、时长、折扣力度）**一个都不写**。
  需要数字的地方写成 `【待填：____】`，让用户自己填。
- **不写医疗/功效承诺**。"治疗""根治""百分百有效""国家级"这类词一律不出现
  —— 这类词既违规，也是用户被罚的重点。
- **不用"最"字**（最好/最低价/第一）。要表达层次就用可验证的说法
  （"比同类少 3 道工序"）。
- **不写虚词填充**。"匠心打造""倾情巨献""震撼来袭"这类词删掉，
  删完句子还成立就说明它本来就不该在。
- **每个版本都要能独立使用** —— 不要出现"如上所述""接上条"。

## 收尾

- 六个版本**并排**给，不要串成一段。
- 末尾加一句「⚠️ 我用了这些事实：…；没用的、需要你补的：…」——
  让人一眼看出哪些是你说过的话，哪些是待填的空。
- 用户挑了某一版要改写：**只改那一版**，别把六个版本重新洗一遍。
